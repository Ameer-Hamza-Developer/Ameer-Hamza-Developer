### What I do

**4+ years** building cross-platform mobile apps. One codebase, native feel on both platforms.

- 📱 **Cross-platform apps** — React Native, TypeScript, Redux, Firebase. Clean architecture a second developer can actually pick up.
- 🔌 **The hard native bits** — push notifications, deep linking, maps, payment gateways, and third-party native SDKs. The integrations most React Native projects get stuck on.
- 🚀 **Ship & iterate** — CI/CD pipelines, OTA updates, staged rollouts. Fixes reach users in hours, not App Store review cycles.
- ⚡ **Performance & stability** — profiling slow screens, cutting startup time, wiring up crash reporting and analytics so product decisions come from data, not guesses.

I care about apps that still feel fast on a mid-range Android device — not just the latest iPhone.
